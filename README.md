- Build and optimize data ingestion, transformation, and orchestration workflows for large-scale datasets.
- Develop efficient ETL/ELT processes and modern data architectures using Azure Data Lake Storage Gen2 (ADLS Gen2).
- Support data migration, modernization, and cloud transformation initiatives across Azure platforms.

### Machine Learning & Data Science
- Develop, deploy, and operationalize machine learning models across the complete ML lifecycle.
- Perform feature engineering, model evaluation, optimization, and performance tuning.
- Build production-ready ML pipelines and automated workflows using Databricks and cloud-native technologies.
- Deliver data-driven insights through analytics, statistical modeling, and predictive solutions.

- Build AI Agents, Retrieval-Augmented Generation (RAG) systems, and intelligent automation solutions.
- Integrate LLMs with enterprise data sources to enable context-aware and scalable AI applications.
- Develop end-to-end AI workflows combining data engineering, machine learning, and Generative AI capabilities.
